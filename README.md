# Blinkit Grocery Sales Analytics Dashboard

## 📈 Key Performance Indicators (KPIs) Captured

The dashboard tracks vital business metrics to assess overall operational health:
* Total Sales: Overall revenue generated across all outlets.
* Average Sales: The average revenue generated per transaction.
* Number of Items: Total volume of products sold.
* Average Rating: Average customer satisfaction score across all deliveries.

---

## 🛠️ Features & Functionality

* Dynamic Slicers: Seamlessly filter the entire dashboard by *Outlet Size* (Small, Medium, High), *Outlet Location* (Tier 1, Tier 2, Tier 3), and *Item Type* for granular analysis.
* Donut Chart Analysis: Breaks down total sales by item fat content to track health-conscious consumer trends.
* Bar/Column Charts: Sales breakdowns by *Item Type* and *Outlet Establishment Year* to monitor growth trends over time.
* Outlet Performance Grid: Direct matrix comparison of sales across various outlet tiers and sizes.
* Custom Navigation System: Built-in interactive buttons to switch fluidly between the main *Dashboard View*, the *Raw Data*, and the underlying *Pivot Tables*.

## 📂 Project Structure

* Blinkit Grocery Data.csv: The raw dataset used for the analysis.
* blinkit excel dashboard.xlsx: The final workbook containing the processed data, pivot tables, and the interactive UI.

## 🚀 Learning Objectives & Core Skills Applied

This project was built to master the fundamental workflows of a Data Analyst:
1. Data Cleaning & ETL: Handling missing values, organizing structural data, and preparing raw grocery records for analytical use.
2. Advanced Pivot Tables: Structuring complex summary tables to drive multiple synchronized visualizations.
3. Dashboard Design & UI/UX: Implementing modern color theory, clear visual hierarchies, grid alignment, and intuitive user layout practices within Excel.
4. Interactivity: Using Report Connections to link Slicers across multiple Pivot Tables for a unified user experience.
